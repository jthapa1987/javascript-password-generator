# 🔐 Password Generator

## Description
A robust, browser-based application designed to generate secure, random passwords based on specific user-defined criteria. This tool ensures sensitive data remains protected by providing passwords that meet modern security standards, including varied lengths and character types.

## 🚀 Live Demo
https://jthapa1987.github.io/javascript-password-generator/

## ✨ Key Features
* **Customizable Length**: Choose a password length between 8 and 128 characters.
* **Character Variety**: Options to include lowercase, uppercase, numeric, and special characters.
* **Real-time Validation**: Ensures at least one character type is selected and the length is within the required range.
* **Responsive UI**: Optimized for desktops, tablets, and mobile devices.

## 🛠️ Built With
* **HTML5**: For semantic structure.
* **CSS3**: For custom styling and responsive layouts.
* **JavaScript (ES6)**: For logic, prompts, and DOM manipulation.

## 📖 How to Use
1.  Click the **"Generate Password"** button.
2.  Enter a desired length (between 8 and 128).
3.  Confirm which character types (Lowercase, Uppercase, Numbers, Special Symbols) to include.
4.  View your secure password generated directly in the text area!
